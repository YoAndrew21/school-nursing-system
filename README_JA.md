# School Nursing System 🩹

[English](README.md) · [Español](README_ES.md) · [日本語](README_JA.md)

チリの学校保健室における実際の業務フローをもとに作成した、プライバシーとオフライン利用を重視するWebアプリケーションです。学校事故申告書の作成、児童・生徒データのローカル管理、ブラウザ内でのPDF生成を支援します。

> **ポートフォリオ版:** UIはスペイン語・英語・日本語に対応しています。ただし、生成されるチリの公式書類はスペイン語のままです。翻訳した書類が他国で法的に同等の書類になるわけではありません。

## 技術的な背景
元の利用環境には専用バックエンドやデータベースを維持するためのインフラ・予算がありませんでした。そのため、データと下書きをブラウザ内に保持し、PDFもローカルで生成するクライアントサイド構成を採用しています。PWAとしてオフラインでも利用できます。

## 主な機能
- スペイン語 / 英語 / 日本語 UI（言語設定をローカル保存）
- チリのRUNの検証・整形
- ブラウザ内PDF生成
- タッチ・スタイラス・マウスによる署名、署名画像の取込
- Excel / XLS / CSVによる一括取込とRUNによる自動入力
- `localStorage` によるローカル保存
- レスポンシブUI・インストール可能なPWA
- Service Workerによるオフライン対応
- Content Security Policyおよびセキュリティヘッダー

## 国際化
`js/i18n.js` にフレームワーク非依存のi18nレイヤーを実装しています。元の業務がチリ向けであるためスペイン語を既定言語とし、英語と日本語を国際向けUIとして追加しています。

## プライバシー
リモートデータベースは不要です。取込データと下書きはブラウザ内に保存されます。**実在する児童・生徒のデータ、署名、生成済み申告書、認証情報、学校の非公開資料をリポジトリへコミットしないでください。**

## 対象範囲
事故申告モジュールは**チリの制度・業務フロー**を対象としています。UI翻訳はアクセシビリティと国際化のためのものであり、他国向けの法的書類を提供するものではありません。
